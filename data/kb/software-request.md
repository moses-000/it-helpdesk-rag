# Installing Software

## Company Portal
Standard approved software can be installed without admin rights through the Company Portal app on your laptop. This includes Adobe Acrobat Reader, Zoom, 7-Zip, Notepad++, Python, Visual Studio Code and Power BI Desktop. Open Company Portal from the Start menu, search for the app, and click Install.

## Software not in Company Portal
Staff do not have local administrator rights. To request software that is not in Company Portal, submit a Software Request in the IT portal with the software name, the business reason and your manager's name. IT Security reviews every new application for licensing and security risk, which normally takes 5 working days. Paid software also needs a cost-centre code approved by your manager.

## Browser extensions
Only extensions on the approved list can be installed in Microsoft Edge and Chrome. Request additional extensions through the Software Request form.

## Unapproved software
Do not install software from personal accounts or download installers from the internet. Unapproved software is detected and removed automatically.
