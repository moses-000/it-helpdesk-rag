# Slow Laptop Performance

## Quick fixes
Restart your laptop – many performance issues are caused by laptops that have not been restarted for weeks, and pending updates only finish installing on restart. Close browser tabs and applications you are not using. Check Task Manager (Ctrl+Shift+Esc) to see which app is using the most CPU or memory.

## Storage
If your C: drive has less than 10% free space, performance drops. Use OneDrive's "Free up space" option on large folders so files stay in the cloud until needed, and empty the Recycle Bin. Do not delete anything from the Windows or Program Files folders.

## Updates
Windows updates are installed automatically and a restart is enforced within 7 days of an update being released. Check Settings > Windows Update to see if an update is waiting for a restart.

## Hardware
Company laptops are replaced every 4 years. If your laptop is still slow after these steps, raise a ticket including the laptop's asset tag (the sticker on the underside starting with HG-). IT will run a remote health check and may arrange a memory upgrade or early replacement.
